Manual Accessibility Tests
Menu Focus Return:

Manually verify that after selecting an item from the main navigation menu using keyboard controls, the focus returns to the menu toggle button (☰).

Steps:

  1. Tab to menu button (☰), press Enter/Space to open.
  2. Tab to a menu item, press Enter to select.
  3. Confirm focus is back on the menu button (☰).
